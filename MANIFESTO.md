# Arwill Manifesto

The architecture is the product.

Arwill is an experimental operating system built through continuous
collaboration between a human architect and AI coding agents. All Arwill-owned
source code is generated from human intent, architectural discussion, review,
and documented decisions.

AI-generated does not mean accepted without review. Human intent and judgment
remain authoritative.

Arwill follows these principles:

1. The architecture is the product.
2. All Arwill source code is generated by AI.
3. Human intent and judgment remain authoritative.
4. Dialogue and decisions precede implementation.
5. Every component should be explainable.
6. Components are replaceable through explicit contracts.
7. Replace a block; do not rewrite unrelated subsystems.
8. Avoid hidden coupling and undocumented global state.
9. Start with one solid platform before pursuing portability.
10. The repository records not only code, but why the code exists.
11. Small, working increments are preferred to large speculative designs.
12. Generated code must be reviewed, tested, and understood.

The project does not value volume of code for its own sake. A small kernel that
boots, explains itself, and can be safely changed is more useful than a large
system whose boundaries are unclear.
